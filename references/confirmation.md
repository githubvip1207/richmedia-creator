# 任务确认单与用户选择

## 数据来源

根据本次任务文件目录 `$WORK/` 下的 `request.json`（其中 `optimized_prompt` 为最新最终提示词）及本次已确定的参数，以及各供应商 `{供应商}-priceing.json` 中的估价生成确认单，不重新计算价格，不引用其他需求的报价；实际文件路径使用脚本返回值，不自行拼接。

确认单先展示用户已确定的需求、最终提示词及输入素材，再分别展示各供应商方案。各方案均须满足用户需求，但可以采用不同模型；每家须列明采用的模型及版本、输出规格、费用和影响选择的限制。供应商选择代表确认该供应商对应的完整方案。不能满足用户需求的供应商不提供生成选项，并说明排除原因。

供应商名称从 `scripts/providers/__init__.py` 的 `PROVIDERS` 注册表读取。仅为满足调用条件的供应商提供生成选项；用户已指定供应商时只展示该家，没有可用供应商时说明原因。

## 展示格式

将完整确认单直接放入 **final 回复正文**，不使用代码块、附件或工具输出代替。

```markdown
# 任务确认单

需求概要：{用户最新有效需求及必须满足的约束}

提示词：{当前 request.json 中 optimized_prompt 的完整内容；无则使用 request.json 中 original_prompt 的完整内容}

输入素材：{无素材时写“无”；有素材时列出可辨认的名称及用途，首尾帧或编辑目标等职责须明确}

供应商方案：

### {供应商名称}

- 模型：{前模型及版本} [{本供应商可选模型}]
- 比例：{当前比例} [{可选比例}]
- 数量：{当前数量} [{可选值}]
- 分辨率：{当前尺寸档位、准确像素或视频分辨率} [{可选值}]
{视频增加时长；其他适用参数沿用上述列表格式}
- 费用预估：{原币金额、区间或未知；有有效汇率时附人民币换算}
- 方案限制：{影响本次选择的限制；无则写“无”}

{每家供应商重复上述方案区块}

生成提示：

- {适用的汇率及过期时间、费用不确定项或影响本次选择的限制}
- 实际费用以供应商结算为准。

以上方案均满足本次已确定的需求，模型及具体规格以各供应商方案为准。请选择供应商确认其对应方案并生成，或选择“我再想想”暂停；也可回复修改要求或取消。
```

- 各供应商方案中的参数分别展示当前值和支持的可选项，供用户调整时参考；可选模型须为该供应商支持且满足当前需求的模型，用户已指定模型时不展示替代模型；其他可选值以该方案当前模型和能力实际支持且满足需求的范围为准。报价对应各方案当前值，用户选择其他值时，按主流程更新方案、重新估价并确认。
- 金额、汇率及有效期以成本结果为准；无有效汇率时保留原币，费用上界未知时明确标注。
- 数量及其可选值以当前生成任务支持的范围为准；不支持单次多张时告知用户，不提供通过多次提交实现多张的选项。
- 不展示 Token、价格快照来源、API 端点、凭证和其他内部字段。

## 用户选择

使用 `request_user_input_async` 展示选项。该工具既支持选项，也允许用户自由输入；调用立即返回，实际回答通过后续用户消息到达。

1. 按本次可用供应商生成 `{供应商名称}，确认生成` 选项；费用上界未知时改为 `{供应商名称}，接受费用上界未知并确认生成`。末尾仅追加 `我再想想`。
2. 调用后以完整确认单作为 final 回复结束本轮。
3. 选择 `我再想想` 时暂停并等待后续指示；未回复、预选或关闭控件均不算确认，也不主动循环调整确认单。用户明确取消时结束任务；自由输入修改需求时，回到相关步骤更新方案、重新估价并确认。

调用示例（选项由本次供应商生成）：

```javascript
request_user_input_async({
  questions: [{
    title: "请选择本次任务确认单的方案",
    options: [...supplierConfirmationOptions, "我再想想"]
  }]
})
```

工具不可用时，在 final 正文展示确认单并等待用户明确回复，不将 Markdown 列表当作可点击按钮。
