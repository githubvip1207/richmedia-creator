# Volcengine · 视频延长（`operation=extend-video`）

## 生成要求

- 参数要求

| 参数 | 必须性 | 可选项 / 默认值 |
|---|---|---|
| `prompt` | 必需 | |
| `mode` | 必需 | `before`：在原视频开始之前生成；`after`：在原视频结束之后生成。没有默认方向，不能从上下文确定时先澄清 |
| `assets` | 必需 | 至少 1 段待延长视频，可同时提供辅助图片、视频、音频。按确认顺序提供素材，来源及限制见下文素材要求。 |
| `ratio` | 必需 | 2.5 固定 `adaptive`；2.0 系列支持 `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive`，默认 `adaptive` |
| `duration` | 必需 | 2.5 支持整数 4～30 秒或 `-1`；2.0 系列支持整数 4～15 秒或 `-1`；无默认值，须明确输出时长；`-1` 由模型选择时长 |
| `resolution` | 必需 | 参考[模型列表](../volcengine.md#模型列表)中的分辨率约束；无默认值，须明确分辨率 |
| `generate_audio` | 必需 | 是否生成音频；默认 `true`；用户要求无声时设为 `false` |

`duration` 表示传给接口的输出时长，不自动与源视频时长相加。用户只说“增加几秒”且无法确定期望的输出片段时长或最终总时长时，先澄清；不擅自截断、拼接原视频，也不把有限时长的输出描述为完整拼接成片。

- 素材要求

| 素材 | 格式及来源 | 尺寸、大小及时长 |
|---|---|---|
| 图片 | JPEG、PNG、WebP、BMP、TIFF、GIF、HEIC、HEIF；本地绝对路径或 HTTPS URL | 宽高均为 300～6000 px，宽高比 0.4～2.5；每张小于 30 MiB |
| 视频 | MP4、MOV，H.264 / H.265；可访问的 HTTPS URL | 宽高均为 300～6000 px，宽高比 0.4～2.5，总像素 407696～8295044；24～60 FPS；每段不超过 200 MiB |
| 音频 | WAV、MP3；本地绝对路径或 HTTPS URL | 每段不超过 15 MiB |

2.5 最多输入 30 张图片、10 段视频、10 段音频；视频和音频分别累计不超过 30 秒，单段为 2～30 秒。2.0 系列最多输入 9 张图片、3 段视频、3 段音频；视频和音频分别累计不超过 15 秒，单段为 2～15 秒。

脚本通过 `ffprobe` 实测素材信息；视频、音频的容器格式、视频编码与帧率以及各素材大小须能核验。本地图片、音频由 Python 在提交时编码为 Base64；含 Base64 的完整请求不得超过 64 MiB。本地视频不能通过 Base64 提交，须先由用户提供可访问的 HTTPS URL；本技能不自动上传视频。当前脚本不接受 `asset://` 或内联 Base64 素材。

待延长视频始终负责边界状态，其他素材只补充明确指定的外观、道具、动作或声音，不能替代原视频首帧或尾帧。脚本按素材类型添加 `reference_image`、`reference_video`、`reference_audio`；不混入首尾帧接口角色。

- 提示词优化

在主流程第 2 步落实本节生成要求时确定最终提示词，供估价和确认单使用；以下生成步骤只使用已确认的最终提示词，不再改写。
本能力要求使用 `sd25-pe` 优化提示词，仅应用与当前视频能力相关的规则，最终提示词须符合所选模型的要求。用户明确要求不优化时，按主流程将完整拼接的 `original_prompt` 原样赋给 `optimized_prompt`，不调用本地提示词优化。

向后延长须明确待延长视频，新增片段从原视频尾帧的主体姿态、道具位置、背景、机位、光线、声音和运动趋势自然开始，再描述接下来发生的事件。

向前延长须先描述原视频开始前的事件，再把原视频首帧作为新增片段的明确结束状态；原视频后续才出现的主体、道具或特效不能提前引入。

同一主体保持为同一个连续对象，不重复、不分裂，身体结构或部件数量保持稳定。延长只创作边界之外的内容，不同时修改源视频。2.5 输出画幅跟随目标视频，不把变更画幅要求写进提示词；分辨率、输出时长及声音开关通过接口参数落实。

- 模式与费用

任务及估价 JSON 顶层均填写 `mode`；初始化记录中写入 `providers.volcengine.mode`，不写入 `intent` 或接口 `payload`。有 `target_asset_id` 时，将其同步到 `providers.volcengine.target_asset_id`、估价输入与提交 JSON 顶层；有 `estimate_context` 时仍完整同步。

2.5 的 `payload.omni_reference_task_type` 固定为 `extend`，方向由提示词明确表达；2.0 系列省略该字段。`mode` 只用于本地记录与校验，不发送给供应商。提示词与方向、目标及任务类型必须一致。

按[视频计费规则](../volcengine.md#文生视频图生视频参考生视频视频延长计费)估价，输入中必须包含当前 `mode`。全部输入视频时长参与计费；多视频目标选择只用于准确定位估价依据，不会替代提示词对目标的说明。输出尺寸或最低计费门槛无法核实时，保留费用不确定项并按主流程确认。

## 生成步骤

以下步骤在用户需要视频延长且确认当前 Volcengine 方案后执行。

1. **构建任务 JSON：** 参考如下示例，基于用户输入的参数和确认的供应商、模型和能力，生成任务 JSON 数据。移除行尾注释后，将严格 JSON 直接追加到下一步命令的标准输入中。以下示例为向后延长，分辨率和时长为本例已确认值，不作为默认值。

   ```jsonc
   {
     "provider": "volcengine", // 必需：供应商，供脚本选择对应适配器
     "operation": "extend-video", // 必需：能力，供脚本选择接口及结果处理方式
     "mode": "after", // 必需：before 向前延长、after 向后延长；须与确认单一致，不提交给供应商
     // 多视频延长时必填：引用 assets 中待延长视频的 id，不按数组下标编号。
     // 单视频时可省略；仅供技能估价和规格核验，不提交给供应商。
     "target_asset_id": "source",
     "original_prompt": "将熊猫视频向后延长，输出 4 秒片段，480p，继续草地环境声", // 流程记录：用户原始提示词，不提交给供应商
     "assets": [ // 必需：本方案使用的素材，按输入顺序排列，由脚本解析，不直接提交给供应商
       {
         "id": "source", // 必需：任务内唯一标识，供供应商引用；不是供应商素材 ID
         "kind": "video", // 必需：image、video 或 audio；待延长素材必须为 video
         "source": "https://example.com/panda.mp4", // 必需：执行前替换为实际 HTTPS URL；图片、音频也可使用本地绝对路径
         "purpose": "待向后延长的视频，尾帧定义新增片段的起点" // 必需：素材用途，只在这里记录一次
       }
     ],
     "payload": { // 必需：火山引擎请求参数，脚本校验模型、参数及需求记录，解析外层 assets 并填充带角色的素材项后提交，不改写提示词；调用约定见脚本操作手册“提交生成”
       "model": "doubao-seedance-2-5-260628", // 必需：准确模型 ID；使用 2.0 系列时替换为对应 ID
       "content": [ // 必需：仅填写文本项；素材项由 Python 根据外层 assets 按顺序添加
         {
           "type": "text", // 固定：文本提示词
           "text": "向后延长视频1。新增片段从视频1的尾帧自然开始，承接熊猫姿态、草地、固定机位、阳光和环境声；熊猫接着挥手，然后转身离开。熊猫始终保持为同一个连续对象，不重复、不分裂，身体结构保持稳定。" // 必需：读取当前 request.json 的 optimized_prompt，须与确认单一致，不再改写
         }
       ],
       "omni_reference_task_type": "extend", // 必需：2.5 固定 extend；2.0 系列省略此字段
       "resolution": "480p", // 必需：所选模型支持的分辨率；无默认值，须明确分辨率
       "ratio": "adaptive", // 必需：2.5 固定 adaptive；2.0 系列支持的比例见参数要求，默认 adaptive
       "duration": 4, // 必需：2.5 为整数 4～30 秒或 -1，2.0 系列为整数 4～15 秒或 -1；无默认值，须明确输出时长
       "tools": [{"type":"web_search"}], // 本例 2.5 默认开启；使用 2.0 系列且含素材输入时必须改为 []
       "generate_audio": true, // 必需：是否生成音频；默认 true，用户要求无声时设为 false
       "watermark": false, // 固定：不加平台水印
       "return_last_frame": false, // 固定：不返回末帧
       "output_format": "mp4" // 固定：MP4；2.0 系列固定输出 MP4，省略此字段
     }
   }
   ```

   `service_tier` 固定省略，普通在线生成使用服务端默认行为。

   向前延长时将 `mode` 改为 `before`，并采用当前已确认的向前延长提示词，例如“向前延长视频1。原视频开始之前，熊猫从草地左侧走入画面，停下并抬起前爪；新增片段最后一帧自然衔接视频1首帧，保持姿态、草地、机位、光线、环境声与运动趋势一致。熊猫始终保持为同一个连续对象，不重复、不分裂，身体结构保持稳定。”。素材的 `purpose` 同步改为首帧负责结束边界，不能只改 `mode` 而保留向后延长描述。

2. **调用脚本提交生成：** 使用上一步构建的 JSON 对象通过 `python3 "$SKILL/scripts/main.py" submit` 提交生成任务。使用本次任务文件目录 `$WORK` 作为 `--workdir`。脚本校验通过后将已确认的完整请求保存为 `$WORK/payload.json`；每次提交及其输出分别保存为 `submit-NNN.json` 和 `output-NNN/`。任务文件目录、提交序号及记录文件由脚本管理；记录返回的当前序号，并将提交文件路径记为 `$SUBMISSION`，供后续使用，不自行递增编号或拼接路径。命令示例见脚本操作手册。
3. **判断生成结果：** 调用 `python3 "$SKILL/scripts/main.py" status` 检查生成任务状态；`queued`、`running` 表示尚未完成，继续查询同一任务，不重新提交。如果失败则提示用户，如果成功则继续交付。提交结果未知时按脚本操作手册的失败处理规则核对原任务。
4. **交付结果：** 调用 `python3 "$SKILL/scripts/main.py" deliver` 获取并校验生成结果，将最终视频交付到启动本技能时所在的当前项目目录，并返回交付文件清单。完成后进入主流程的内容核验与结果展示步骤。

视频核验时，向后延长比较新增片段开头与源视频尾帧，向前延长比较新增片段结尾与源视频首帧；检查主体、姿态、道具、场景、机位、运动方向及声音是否自然连续，并核验交付文件实测时长、分辨率和音轨。边界不保证像素级相同，声音可能存在音量差异；发现不符时说明具体问题，再次付费修正须重新确认。

接口参数依据：[创建视频生成任务](https://console.volcengine.com/ark/region:cn-beijing/docs/create-video-generation-task-api)。
